## معايير الاتصال

### API Response Format

```json
{
  "success": true,
  "data": {
    "id": "uuid",
    "name": "example"
  },
  "message": "Operation successful",
  "timestamp": "2026-09-26T10:30:00Z"
}
```

### Error Response Format

```json
{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Invalid email format",
    "details": ["Email must be valid"]
  },
  "timestamp": "2026-09-26T10:30:00Z"
}
```

## تكامل الخدمات الخارجية

### Cloudinary (Image Upload)
```
User → Frontend → Backend → Cloudinary → CloudURL → Database
```

### Stripe (Payment)
```
User → Payment Form → Stripe → Webhook → Backend → Database
```

### Google Maps
```
Frontend → Google Maps API → Display Location
```

### SendGrid (Email)
```
Backend Event → SendGrid → User Email
```

## Caching Strategy

```
┌──────────────────┐
│ User Request     │
└────────┬─────────┘
         │
    ┌────▼────────────────┐
    │ Check Redis Cache    │
    └────┬────────────────┘
         │
    ┌────▼──────────────────────┐
    │ Cache Hit? ✓              │
    │ → Return Cached Data      │
    └──────────────────────────┘
         │
    ┌────▼──────────────────────┐
    │ Cache Miss? ✗             │
    │ → Query Database          │
    └────┬─────────────────────┘
         │
    ┌────▼──────────────────────┐
    │ Store in Cache            │
    │ (with TTL)                │
    └────┬─────────────────────┘
         │
    ┌────▼──────────────────────┐
    │ Return Data to User       │
    └──────────────────────────┘
```
